De una página a un conjunto de datos

Scraping: recuperar contenido web y transformarlo en registros que podamos analizar.

  • 01
    Entrada. Una fuente y una pregunta delimitadas.
  • 02
    Proceso. Obtener → extraer → limpiar → validar → guardar.
  • 03
    Salida. Una fila por unidad de análisis; columnas con significado estable.

Concepto central · 02

¿Descarga, API o scraping?

Elegir primero el acceso más directo y autorizado.

Descarga

Si existe un CSV adecuado, no reconstruirlo desde la pantalla.

API

Datos estructurados; revisar cobertura, permisos, cuotas y límites históricos.

Scraping

Cuando la información necesaria está en la web y no hay una alternativa adecuada.

Concepto central · 03

Visible no significa listo para analizar

Una noticia mezcla información relevante, navegación y publicidad.

  • 01
    Unidad. Una noticia, no cada bloque de texto de la página.
  • 02
    Campos. Título, fecha, medio, URL y cuerpo: definirlos antes de extraer.
  • 03
    Ausencias. Un dato faltante se registra como tal: no se completa por intuición.

Concepto central · 04

Tres herramientas, distintas tareas

La estrategia depende de cómo llega el contenido al navegador.

R

rvest y xml2: extraer HTML y organizar datos para análisis.

Python

Requests, BeautifulSoup y pandas: capturar y procesar series de páginas.

Playwright

Navegar e interactuar cuando se necesita ejecutar JavaScript.

Concepto central · 05

IA: ayuda técnica, no evidencia

La IA puede proponer código y reglas; los datos deben proceder de la fuente.

  • 01
    Asistencia. Explicar HTML, sugerir selectores y ayudar a depurar.
  • 02
    Extracción contextual. Interpretar fragmentos ambiguos sin inventar campos ausentes.
  • 03
    Verificación. Contrastar registros con las páginas y conservar su procedencia.
07 / 08

Concepto central · 06

¿Qué hace un agente?

Un agente combina un modelo, herramientas y decisiones dentro de un objetivo acotado.

  • 01
    Observar. Inspeccionar una página o recibir un fragmento de HTML.
  • 02
    Actuar. Elegir una herramienta, extraer y evaluar el resultado.
  • 03
    Detenerse. Finalizar ante el objetivo, un límite de costo o una restricción de acceso.
08 / 08

Concepto central · 07

Antes de capturar, definir el contrato

Un pedido preciso evita obtener una tabla correcta para una pregunta equivocada.

  • 01
    Alcance. Fuente, período, unidad de análisis y campos.
  • 02
    Límites. Permisos, volumen máximo, frecuencia y datos que no se recopilarán.
  • 03
    Éxito. Muestra revisada, URL y fecha de captura en cada registro.
