Concepto central · 01

HTML organiza; CSS selecciona y presenta

El DOM es la estructura de nodos que el navegador construye a partir del documento.

  • 01
    Etiquetas. article, h2, a y time describen partes del contenido.
  • 02
    Atributos. href contiene un destino; class e id ayudan a localizar nodos.
  • 03
    Relaciones. Padres, hijos y hermanos permiten extraer campos dentro de cada registro.
<article class="noticia">
  <h2 class="titulo">
    <a href="/politica/…">Título de la noticia</a>
  </h2>
  <time datetime="2026-10-18">18 oct</time>
</article>

Concepto central · 02

Selectores: localizar sin adivinar

Un selector es una regla para encontrar nodos, no una descripción en lenguaje natural.

CSS

article h2 a: enlaces dentro de títulos de artículos.

CSS por atributo

a[href]: enlaces que tienen atributo href.

XPath

//article//h2/a: un recorrido equivalente para esta estructura.

Concepto central · 04

HTML recibido ≠ DOM renderizado

Una página puede mostrar datos que no estaban en su respuesta HTML inicial.

  • 01
    Estática. El HTML descargado ya contiene el contenido necesario.
  • 02
    Dinámica. JavaScript agrega o modifica contenido tras cargar.
  • 03
    Comprobación. Comparar respuesta inicial, DOM y solicitudes; no decidir solo por el aspecto.

Concepto central · 06

Selectores que sobreviven mejor

Priorizar estructura y atributos estables; revisar que la selección sea específica.

  • 01
    Evitar fragilidad. Clases generadas y cadenas largas con nth-child cambian con facilidad.
  • 02
    Extraer por registro. Buscar título, fecha y enlace dentro del mismo artículo.
  • 03
    Validar. Comprobar casos con campos ausentes y varios tipos de página.

IA · pedido de ejemplo

Pedir ayuda a la IA con evidencia

Copiar desde DevTools solo el bloque del listado, no la página entera. Con sesión iniciada, revisar que no se cuelen nombre, email ni tokens.

Analiza la portada de sección https://www.eldiario.es/politica/. Te pego el HTML del bloque del listado copiado desde DevTools. Identifica el elemento que contiene cada noticia y propón selectores CSS y XPath para el título, el enlace absoluto y la fecha. En este listado, la mayoría de las noticias no muestra fecha: indica cuántas la tienen y propón cómo obtener la que falta desde la página de cada artículo, por ejemplo con meta o time. No inventes clases ni nodos que no aparezcan en el fragmento. Termina con una prueba en la consola del navegador (document.querySelectorAll) que cuente las coincidencias y las compare con las noticias visibles.
